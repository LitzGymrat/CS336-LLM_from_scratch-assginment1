## 8 与 128 进程的预分词比较

两次专门测量均使用完整 OWT 验证集、128 个文件块，以及相同源码。每个配置测量一次，未同时运行其他训练任务。合并步骤没有在 128 进程测量中重复执行。

| 工作进程数 | 预分词阶段耗时 | 进程组 RSS 采样峰值 |
|---|---:|---:|
| 8 | 8.308 秒 | 1.934 GiB |
| 128 | 16.383 秒 | 5.061 GiB |

128 进程耗时约为 8 进程的 1.97 倍。两次初始频次表的完整 SHA-256 一致，片段种类和总频次也一致。由此正式训练选择 8 个进程、128 个分块。

## 验证范围

实际多进程训练入口通过三个官方训练测试。训练函数与此前验证的 TinyStories 版本进行 AST 比较，一致。OWT 验证集产物额外通过：词表大小与连续 ID、基础字节与特殊 token、字节内容唯一性、合并父 token 可用性与顺序、特殊 token 不参与普通合并、输入文件哈希、全部分块边界、小样本编码解码以及非法 UTF-8 替换检查。

[检查结果](../../../data/bpe_benchmarks/20260915-211141-057984-multiprocess-8p-128c-owt-valid-32000-baseline/validation.json)。没有将 OWT 全语料的编码 ID 与独立参考编码器逐项比较。RSS 是采样的进程组总和，可能重复计算共享内存，也可能漏掉短暂峰值。
