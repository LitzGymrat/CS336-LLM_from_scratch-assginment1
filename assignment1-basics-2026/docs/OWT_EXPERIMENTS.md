|---|---|
| 模型 | 4 层、16 头，`d_model=512`、`d_ff=1344`；Pre-RMSNorm、RoPE、SwiGLU |

| 其他 | 全局梯度裁剪 1.0；seed=42；MPS、float32 |
| 评估与保存 | 每 100 步评估；每 1,000 步及训练结束时保存 checkpoint |

实际运行配置已与 TinyStories 基线核对，23 项公共训练设置一致。更换语料与词表后，embedding 和 LM head 的参数量与运算量随之增加，因此这是相同结构设置、训练步数和 token 预算的对照，不是严格相同 FLOPs 的对照。不同 tokenizer 的每 token 损失也需要结合其切分粒度解释。

训练每步随机采样新 batch，数据通过 NumPy mmap 按需读取。曲线中的训练损失在固定 1 个训练 batch 上计算，验证损失在固定 4 个验证 batch（32,768 token）上取平均，均不代表完整数据集评估。
