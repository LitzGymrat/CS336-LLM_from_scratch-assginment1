## 7. KV Cache experiment

这会是 README 里最亮眼的一节之一。

### 建议结构

#### What

Implemented cached decoding to avoid recomputing keys/values for previous tokens.

#### Why

Autoregressive generation without cache recomputes the entire prefix at every step.

#### Result

放你现在这个 benchmark：

- baseline: 113.47 tokens/s
- KV cache: 282.69 tokens/s
- speedup: 2.49x

最好再配一张图：

- generation speed comparison  
    或
- total decoding time vs generated length
